📈 Medical Insurance Cost Prediction System

This project is a collaborative data science initiative focused on predicting medical insurance costs using demographic and health-related factors. Using Python, statistical analysis, and regression modeling, the team investigates how age, BMI, smoking status, number of children, sex, and region influence insurance charges.

The project includes data cleaning, exploratory data analysis (EDA), feature engineering, regression modeling, statistical inference, and model evaluation. It also demonstrates effective team collaboration using GitHub, feature branches, pull requests, and Scrum practices.

🎯 Research Question

Can we predict a person's medical insurance cost based on their age, BMI, smoking status, number of children, sex, and region?
